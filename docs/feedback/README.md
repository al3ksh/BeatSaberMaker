# VR feedback notes

After play-testing a generated map in Beat Saber, write what you noticed here.

- One file per play session, named `YYYY-MM-DD.md`.
- For every map tested give: the folder name (`BSM - ...`), the `--seed` and `--nps` used, and the checkpoint step if you know it.
- Then list what felt wrong and when: song time (mm:ss) or a rough part of the song, which hand, and what it was (awkward swing, wrong rhythm, notes off the beat, too dense or too sparse, unreadable pattern, reset needed).
- Also note what felt good; it tells us what to keep.
- Run `bsmaker preview` first if sync felt off, and say whether the click track was also off.

Short bullet points are enough.
